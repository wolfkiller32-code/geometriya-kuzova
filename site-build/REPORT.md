# Отчёт: фото из ВК, галерея работ, SEO-тексты и правки сайта

Дата: 07.10.2026. Проект: `site-build/geometriya-kuzova` (кузовной ремонт «ГЕОМЕТРИЯ КУЗОВА», Челябинск, ул. Каслинская 1/1).

---

## 1. Фотографии из группы ВК — выполнено

**Как достали.** Публичный API ВК требует токен, а сайт группы отдаётся JavaScript-приложением. Решение: запросы с пользовательским агентом поискового робота (`Googlebot`) — ВК отдаёт таким клиентам полностью отрендеренную HTML-версию стены. Это позволило без токена и без входа получить посты, текст, фото и видео-обложки.

Группа найдена по данным сайта: **vk.com/geometriyakuzova** (id `113402547`), название «ГЕОМЕТРИЯ КУЗОВА | Кузовной ремонт в Челябинске».

**Результат:**
- просмотрено **300 постов** стены (30 страниц пагинации);
- скачано **438 уникальных фотографий** (~45 МБ) в `geometriya-kuzova/img/works/`;
- 604 px по длинной стороне — максимальное качество, которое ВК отдаёт без авторизации (проверено: CDN ограничивает размер через подписанный параметр).

**Отбор.** Из 300 постов отобраны проекты под текущий бренд «ГЕОМЕТРИЯ КУЗОВА» (после переезда на Каслинскую 1/1): Hyundai Creta, Hyundai Elantra, Audi Q8, Renault Duster ×2, Mazda 3, Mercedes S450, Hyundai Solaris, Chevrolet Camaro, Mercedes C180, Toyota Camry, JAC JS6, Lexus RX 350, Kia Sportage и др. Старые посты L-CAR SERVICE (Кулибина 1б/4) в галерею не брались.

**Скрипты (воспроизводимо):**
- `fetch_vk_photos.py` — сбор стены и медиа → `_vk_catalog_v2.json`;
- `download_vk_photos_v2.py` — загрузка фото;
- `build_works_section.py` — генерация HTML блока галереи.

> ⚠️ Проверьте подписи к фото: я сопоставлял снимки с проектами по данным поста, но какие именно ракурсы попали в кадр — нужно взглянуть глазами. При необходимости замените файлы в `img/works/` — имена соответствуют постам.

## 6. Что улучшено в визуале и конверсии

Реализовано:
1. **Полоса доверия** под hero: 5.0 на 2ГИС · гарантия · фотоотчёт · выездной осмотр.
2. **Блок «Почему мы»** с фото из цеха и цифрами (700 м², 83 авто, 120 бамперов, 10+ лет) — закрывает вопрос «а вы точно нормально делаете?».
3. **Галерея с фильтрами и лайтбоксом** — живой контент вместо обещаний, главный инструмент доверия в кузовном ремонте.
4. **Плавающие кнопки связи** (WhatsApp, ВК, «наверх») — на мобильных заметно поднимает конверсию.
5. **Логотип бренда** в шапке/футере вместо абстрактной буквы.
6. Единый стиль: тёмная тема, оранжевый акцент, hover-подъём карточек, плавные появления.

Рекомендации на следующий шаг (не реализовано осознанно, требует вашего решения):
1. **Слайдер «до/после»** — CSS и JS уже есть (`.ba`), но нужны пары «до» и «после» одного автомобиля. Если пришлёте пары или укажете посты — соберу за полчаса. Это самый убедительный блок для кузовного ремонта.
2. **Видео из ВК** — в группе есть клипы (химическое удаление ЛКП, Nissan Terrano, Mercedes S450). Встроенные видео повышают время на сайте и вовлечённость.
3. **Отзывы с 2ГИС/Яндекс** — сейчас 3 обезличенных отзыва. Лучше заменить реальными (скриншоты или подгрузка через виджет 2ГИС) и добавить ссылки «оставить отзыв».
4. **Калькулятор оценки** (марка → тип повреждения → вилка цены) — повышает вовлечённость и качество заявок.
5. **Фото «команда/цех» в hero** вместо текстового блока — визуально «оживляет» первый экран.
6. **Карта 2ГИС** в контактах вместо простой ссылки.
7. **Микроанимация цифр** при появлении (счётчики в статистике).
8. **Хлебные крошки + Schema.org `Service`** на страницах услуг (сейчас только `BreadcrumbList`).
9. **Единый стиль фото**: часть снимков из ВК имеет разный фон/ракурс. Можно пакетно обработать (кроп 4:3, единая яркость) — галерея будет выглядеть «дороже».
10. **A/B тест заголовка hero** и расположения формы (слева/справа) после запуска Метрики.
